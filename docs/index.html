Before you start
  • You need access to the app in Databricks (your team admin uses Share → Can Use on the app).
  • You also need a role in the app (Maker, Checker, or Admin) set by RCO in User Role Manager.
  • At the top of the app you’ll see your role, department (if applicable), and email.

Need threshold formats, validation rules, or page-by-page technical detail? See the technical reference (for power users and RCO admins).
